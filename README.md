# 우리집 에이스 (에이스 홈)

수학 에이스·한자 에이스로 가는 입구이자, 두 과목에서 모은 별을 함께 쓰는 곳입니다.

- 아이 모드: 과목 바로 가기, 합산 별, 찬스 가게, 내 쿠폰, 명예의 전당
- 부모님 모드: 쿠폰 사용 처리·되돌리기, 별 주기·빼기, 별 내역, 기기 동기화, AI 키(모든 에이스 공통), PIN

규칙: 프로젝트 문서 `common/star-chance-rules.md`, 설계: `common/hub-design.md`

## 공통 모듈 `src/ace`

허브·수학·한자 세 저장소에 같은 파일이 들어 있습니다. 고치면 세 곳에 똑같이 복사합니다.

| 파일 | 역할 |
| --- | --- |
| `wallet.ts` | 별 계산, 힌트·찬스·쿠폰, 부모님이 준 별, 축하·명예의 전당 |
| `chances.ts` | 찬스 목록과 단계(가격·구매 제한·유효기간) |
| `aceSync.ts` | 지갑·한자 기록 기기 간 동기화 (수학과 같은 GAS 서버, 이름표 wallet·hanja) |
| `links.ts` | 앱 주소와 과목 목록(새 과목은 SUBJECTS에 한 줄 추가) |
| `settings.ts` | 공통 설정: Gemini API 키 (에이스 홈 키가 먼저, 기기 안에만 저장) |
| `AceNav.tsx` | 과목 앱 아이 홈의 "에이스 홈 · 다른 에이스" 이동 버튼 |
